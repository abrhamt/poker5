# Project Guidelines & Architecture Rules

## Core Technologies
1. **Web Framework**: Fiber v3 (`github.com/gofiber/fiber/v3`).
2. **Database Engine**: MySQL.
3. **Database ORM/Code Generator**: `sqlc` (type-safe SQL compiler).

## Code Structure & Quality Rules
1. **File Length Limit**: Strictly NO files larger than **500 lines of code**. Large files must be broken down into smaller focused files/modules.
2. **Zero Hand-Written Code Comments**: Do NOT write any inline, block, or docstring comments inside hand-written code files at all (generated code from sqlc may retain generated headers).
3. **Modular Layered Architecture**: Code MUST be strictly separated into the following layer packages:
   - `handlers/`: HTTP presentation layer (Fiber v3 handlers, requests & response serialization).
   - `services/`: Core business logic services (game rules, wallet operations, auth, SSE event orchestration).
   - `repository/`: Database access layer (generated by `sqlc` + raw database connection pooling for MySQL).
   - `utilities/`: Shared helper functions, password hashing, 10-char transaction ID generators, and security utilities.
